# Project 1 — Chess Tournament | corrected submission package

This folder contains a corrected Quarto code base, a fully matching video-explainer Quarto report, the original course tournament text, and the exported 64-row CSV.

## Files
- DATA607_Project1_Chess.qmd — main submission
- Project01_VIDEO_SPEAKER_NOTES.qmd — full presentation copy, same 9 executable R chunks plus on-screen narration
- tournamentinfo.txt — original course-provided tournament data
- chess_tournament_clean.csv — output data, five required columns
- VERIFICATION_AND_SUBMISSION.md — audit and next steps

## Reproduce on either computer
1. Download these five files together into a single local folder.
2. Install R, RStudio, Quarto, and tidyverse if needed. Run in R: install.packages("tidyverse").
3. Open DATA607_Project1_Chess.qmd in RStudio and select Render. Keep tournamentinfo.txt beside it.
4. Open Project01_VIDEO_SPEAKER_NOTES.qmd on the presentation computer. It contains the same R code and charts with speaker notes directly after relevant headings.
5. Check both rendered reports and record the video explanation before uploading it to Brightspace.

The GitHub files are source files, not proof of a completed local Quarto render. No video has been recorded, and nothing has been submitted to Brightspace.
